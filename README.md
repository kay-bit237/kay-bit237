## About Me

I work on the frontline of security operations, triaging alerts, reviewing logs, and investigating suspicious activity to catch threats early. I escalate when needed, support incident response, and keep improving detection by tuning alerts, cutting false positives, and keeping our security posture aligned with internal policy and regulatory requirements.

Outside of work, I build hands on labs in Azure and Microsoft security tools to keep sharpening the same skills I use on the job.

<br>

## What I Do

* **Alert triage and investigation:** reviewing logs, correlating events, and separating noise from real threats
* **Incident response:** escalation, containment support, and documentation
* **Detection engineering:** tuning alerts and reducing false positives
* **Cloud security:** Azure identity, storage, logging, and monitoring
* **Security awareness:** phishing simulation and user training
